# Task 01 — Shopping Bill (GST First, Discount After)

This repository contains the Python and Java solutions for the Kiran Academy task.

## Sample result
- Electronics after 18% GST: Rs. 236.00
- Fashion after 13% GST: Rs. 226.00
- Food after 7% GST: Rs. 107.00
- Total after GST: Rs. 569.00
- Discount (20%): Rs. 113.80
- Final payable amount: Rs. 455.20

## Run Python
```bash
python shopping_bill.py
```

## Run Java
```bash
javac ShoppingBill.java
java ShoppingBill
```

The sample values are passed directly in the code. The program does not ask the user for input, and each calculation function/method returns its amount.
